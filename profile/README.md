# Delta Arc

Delta Arc develops demand-intelligence and contextual-reasoning systems around real operating decisions. We also publish independent industrial research through [The Machine Blue Book](https://themachinebluebook.com/), a practical reference for machine specifications, value context, ownership decisions, industrial services, and original market reports.

## Public research

- [Machine Blue Book research repository](https://github.com/deltaarc-hq/machine-blue-book-research)
- [2026 Used CNC Machine Market Report](https://themachinebluebook.com/reports/2026-used-cnc-machine-market/)
- [Permanent report DOI](https://doi.org/10.5281/zenodo.23106776)
- [Research library](https://themachinebluebook.com/reports/)
- [Methodology and source notes](https://themachinebluebook.com/reports/2026-used-cnc-machine-market/methodology/)

The public research package contains aggregate data, citation metadata, integrity hashes, and a preserved copy of the report. It does not publish personal information or row-level third-party listing data.
